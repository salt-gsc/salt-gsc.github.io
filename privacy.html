Privacy policy

Last updated: 14 November 2026

salt is an internal assistant used by one small team. Its only Google integration is read-only access (gmail.readonly) to its own mailbox. No other Google account is accessed.

What is accessed

salt reads messages in its own mailbox only from senders on an allowlist kept by the team. It cannot send, modify or delete email.

How it is used

Message content is used only to help the team with its own work, for example noticing invitations or notifications. It is not sold, shared with third parties, used for advertising, or used to train AI models.

Storage

OAuth tokens are stored on the team's own server with restricted file permissions. Messages are not copied out of Gmail except as short notes for the team.

Google API Services User Data Policy

salt's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
